# 🚀 Gesture App Project Documentation

This project consists of two main components:
1.  **Backend & Admin Portal** (Laravel)
2.  **Mobile Application** (Flutter)

## 🛠 Prerequisites

Ensure you have the following installed on your machine:

*   **PHP** (v8.1 or higher)
*   **Composer** (PHP Dependency Manager)
*   **Node.js & NPM** (For compiling Admin assets if needed)
*   **Database** (MySQL / MariaDB / SQLite)
*   **Flutter SDK** (Latest Stable)
*   **Android Studio / VS Code** (For Mobile App development)

## 🖥️ 1. Running the Backend & Admin Portal

The backend is built with **Laravel**. It provides the API for the mobile app and the Admin Portal interface.

### Steps:

1.  **Navigate to the Backend directory**:
    ```bash
    cd backend
    ```

2.  **Install PHP Dependencies**:
    ```bash
    composer install
    ```

3.  **Setup Environment**:
    *   Copy `.env.example` to `.env` (if not already present):
        ```bash
        cp .env.example .env
        ```
    *   Configure your database credentials in `.env`:
        ```ini
        DB_CONNECTION=mysql
        DB_HOST=127.0.0.1
        DB_PORT=3306
        DB_DATABASE=gesture_db
        DB_USERNAME=root
        DB_PASSWORD=
        ```

4.  **Generate App Key**:
    ```bash
    php artisan key:generate
    ```

5.  **Run Migrations & Seeders**:
    This creates the database tables and default users.
    ```bash
    php artisan migrate --seed
    ```

6.  **Serve the Application**:
    ```bash
    php artisan serve
    ```

### Accessing the Portal:
*   **Backend URL**: `http://127.0.0.1:8000`
*   **Admin Portal**: `http://127.0.0.1:8000/admin/login`
    *   The Admin Portal is integrated into the backend.
    *   *Default User*: `test@example.com` (Password: `password`)

## 📱 2. Running the Mobile Application

The mobile app is built with **Flutter** and resides in the `gesture_app_new` directory.

### Steps:

1.  **Navigate to the App directory**:
    ```bash
    cd gesture_app_new
    ```

2.  **Install Flutter Dependencies**:
    ```bash
    flutter pub get
    ```

3.  **Configure API Endpoint**:
    *   Ensure the app points to your local backend IP.
    *   If running on a real device, use your machine's local IP (e.g., `192.168.1.x:8000`) instead of `localhost`.
    *   *Check `lib/core/constants.dart` or `.env` if applicable.*

4.  **Run the App**:
    *   Connect your Android device (USB Debugging must be ON).
    *   Run:
        ```bash
        flutter run
        ```
    *   **Release Build** (for APK):
        ```bash
        flutter build apk --release
        ```
        *Output Location*: `build/app/outputs/flutter-apk/app-release.apk`

## 🔑 Permissions Check

For the Overlay features to work on Android:
1.  **Display Over Other Apps**: The app will request this permission. Grant it manually if prompted.
2.  **Notification Permission**: Required for the foreground service notification.
3.  **Accessibility Service**: (Optional) Required only if "Global Actions" like Home/Back are implemented.
